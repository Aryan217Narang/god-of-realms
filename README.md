## 🌟 Overview

**God of Realms** turns everyday study habits into an immersive RPG journey. Every minute you study earns XP, unlocks ancient relics, levels up your character, and visually transforms individual fantasy realms with custom pixel-art elements.

---

## 🏰 The Five Distinct Realms

Each subject connects to a unique environmental biome with its own topology, color palette, and unlockable landmarks:

| Realm | Subject | Biome / Theme | Key Landmarks |
| :--- | :--- | :--- | :--- |
| **Forest Realm** | **DAA** (Design & Analysis of Algorithms) | Lush Emerald Woodlands | Ancient Oak, Algorithm Roots, Mana Canopy, Wisdom Tree |
| **Volcano Realm** | **OS** (Operating Systems) | Fiery Magma Peaks & Lava | Obsidian Ridge, Molten Crater, Core Hearth, Volcanic Spire |
| **Cherry Blossom Realm** | **NoSQL** (Non-relational Databases) | Radiant Sakura Blossom Grove | Sakura Trees, Petal Shrine, Zen Pavilion, Blossom Spring |
| **Cosmic Sky Realm** | **HDA & Cognitive Intelligence** | Violet Astral Floating Island | Sky Spire, Nebula Portal, Floating Monolith, Astral Archive |
| **Desert Realm** | **GV** (Graphics & Visualization) | Golden Dunes & Sunlit Pyramids | Sun Pyramid, Dune Oasis, Pharaoh Spire, Golden Obelisk |

## ✨ Features

- **⏱️ Gamified Study Timer**:
  - Focus sessions with configurable Pomodoro intervals and breaks.
  - Interactive build goals & presets (plant trees, carve magma channels, erect obelisks) randomized on each session.
- **🎨 Dynamic Theme Engine**:
  - **Pink Mode**: Retro pastel aesthetic with pink tones and subtle pixel borders.
  - **Dark Mode**: Sleek obsidian fantasy RPG dashboard with vibrant glow effects.
  - **White Mode**: High-contrast, clean parchment aesthetic with dark typography for daytime readability.
- **📈 Progression & Analytics**:
  - Study statistics with 7-day and 30-day interactive charts (powered by Recharts).
  - Subject distribution breakdowns and all-time study logs.
  - Streaks counter and streak maintenance system.
- **🏆 Achievements & Relics**:
  - Unlockable runes, artifacts, and badges as milestones are reached.
- **💾 Local Persistence**:
  - Instant auto-save via `localStorage` with export and import functionality.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or pnpm / yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/Aryan217Narang/god-of-realms.git

# Navigate into project directory
cd god-of-realms

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
